# Cobies verjaardagskraskaart

Een schermvullende mobiele kraskaart met een cadeau van €250 voor een nieuwe jas.

Geen installatie, npm-pakketten of build nodig. Open index.html of publiceer deze map met GitHub Pages: branch main, map / (root).

Bestanden: index.html, style.css, script.js en prize-cobie.jpg. De afbeelding blijft volledig zichtbaar; eventuele ruimte naast de afbeelding krijgt een passende achtergrond. Krassen werkt met een vinger of muis. Enter of de spatiebalk toont het cadeau ook.
